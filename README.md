## The pitch

> That app idea you've carried for months deserves a first step today — say it in one plain sentence and an AI agent on make.fun will build a working version for you to try, free, no coding needed.

## How it works

`main.ts` writes the pitch above to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It first checks the pitch is 1–240 characters long, counted in Unicode code points, and a single line, and refuses to write anything outside those bounds. No code, no explanation — the sentence is the whole entry.
